# 第四章代码总结

本章代码围绕"色彩空间类型转换"展开，核心函数是 `cv2.cvtColor()`。前半部分用小数组观察通道变化，后半部分用真实图片完成灰度转换、BGR/RGB 互转、HSV 颜色提取、肤色提取、艺术效果和 alpha 通道处理。

---

## 例 4.1 BGR 转灰度图

文件：[例4.1.py](例4.1.py)

核心代码：

```python
rst = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
```

转换公式（ITU-R BT.601 标准）：

```text
Gray = 0.114 × B + 0.587 × G + 0.299 × R
```

三个系数反映人眼对不同颜色光的敏感度：

| 通道 | 系数 | 原因 |
|------|------|------|
| G 绿色 | 0.587 | 人眼对绿光最敏感，权重最大 |
| R 红色 | 0.299 | 人眼对红光次敏感 |
| B 蓝色 | 0.114 | 人眼对蓝光最不敏感，权重最小 |

系数之和为 1.0，本质是亮度的加权平均。BGR → GRAY 是**有损转换**，颜色信息永久丢失，不可逆。

---

## 例 4.2 灰度图转 BGR

文件：[例4.2.py](例4.2.py)

核心代码：

```python
rst = cv2.cvtColor(img, cv2.COLOR_GRAY2BGR)
```

转换方式：**把灰度值直接复制到三个通道**，没有任何加权运算。

```text
灰度值 100 → B=100, G=100, R=100
```

结果 B=G=R 始终相等，所以看起来仍然是灰色。这只是格式上的三通道包装，**不能恢复例 4.1 丢失的彩色信息**。

---

## 例 4.3 BGR 和 RGB 互转

文件：[例4.3.py](例4.3.py)

核心代码：

```python
rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
bgr = cv2.cvtColor(rgb, cv2.COLOR_RGB2BGR)
```

转换方式：**交换第 0 通道和第 2 通道**，不涉及任何数学运算。

```text
BGR: [B, G, R]  →  RGB: [R, G, B]
RGB: [R, G, B]  →  BGR: [B, G, R]
```

两次互换后 `bgr` 和原始 `img` 完全一致。常见错误：`cvtColor` 写错成 `cvtColer`，会报 `AttributeError`。

## 例 4.4 图像在 BGR 和灰度之间转换

文件：[例4.4.py](例4.4.py)

核心代码：

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
bgr = cv2.cvtColor(gray, cv2.COLOR_GRAY2BGR)
```

- `img`：原始彩色图（三通道）
- `gray`：单通道灰度图
- `bgr`：三通道，但 B=G=R，视觉上和 `gray` 完全一样

BGR → GRAY 是有损的，GRAY → BGR 只是复制，所以 `gray`（单通道）和 `bgr`（三通道 B=G=R）看起来都是灰度图——颜色信息回不来了。

## 例 4.6 查看蓝绿红在 HSV 中的值

文件：[例4.6.py](例4.6.py)

核心代码：

```python
# 纯蓝：B=255, G=0, R=0 → HSV(120, 255, 255)
# 纯绿：B=0, G=255, R=0 → HSV( 60, 255, 255)
# 纯红：B=0, G=0, R=255 → HSV(  0, 255, 255)
```

### HSV 三分量的含义

| 分量 | 索引 | 含义 | OpenCV 范围 |
|------|------|------|-------------|
| H（Hue）| `[:,:,0]` | 色调，颜色种类 | 0~180（实际角度÷2） |
| S（Saturation）| `[:,:,1]` | 饱和度，颜色纯度 | 0~255 |
| V（Value）| `[:,:,2]` | 明度，亮度 | 0~255 |

> OpenCV 中 H 是 0~180 而非 0~360，因为 uint8 最大 255 装不下 360。

### H 在色环上的分布

```
OpenCV H:   0 ——→  60 ——→ 120 ——→ 180(=0)
颜色:       红      绿      蓝      红(回到起点)
```

三种原色在色环上各隔 60（实际 120° 的一半），等距分布。

### BGR → HSV 的数学公式

**V（明度）**：取最大值

$$V = \max(B, G, R)$$

**S（饱和度）**：最大值和最小值的差距

$$S = \frac{V - \min(B, G, R)}{V} \quad (V \neq 0)$$

纯色时 min=0，S=1（255）；B=G=R 时 S=0，即灰色。

**H（色调）**：取决于 V 来自哪个通道（以下为实际角度 0~360°，OpenCV 再除以 2）：

| V 的来源 | H 公式 |
|----------|--------|
| V = R | $H = 60 \times \frac{G - B}{V - \min}$ |
| V = G | $H = 120 + 60 \times \frac{B - R}{V - \min}$ |
| V = B | $H = 240 + 60 \times \frac{R - G}{V - \min}$ |

若 H < 0，加 360。最后 ÷2 得到 OpenCV 的 0~180 值。

### 分别提取三个通道

```python
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
H = hsv[:, :, 0]  # 色调
S = hsv[:, :, 1]  # 饱和度
V = hsv[:, :, 2]  # 明度
```

三个分量都在同一个 `hsv` 里，按通道索引取出即可。

## 例 4.7 inRange 标记指定范围

文件：[例4.7.py](例4.7.py)

核心代码：

```python
mask = cv2.inRange(img, min, max)
```

- 在 `[min, max]` 范围内的像素 → mask 中为 **255**（白）
- 不在范围内的像素 → mask 中为 **0**（黑）

`inRange()` 常用于生成二值掩码。常见错误：`size[5,5]` 应写为 `size=[5,5]`，缺等号会报语法错误。

---

## 例 4.8 用掩码显示 ROI

文件：[例4.8.py](例4.8.py)

核心代码：

```python
roi = cv2.bitwise_and(img, img, mask=mask)
```

- mask 非零的位置 → 保留原图像素值
- mask 为 0 的位置 → 变成黑色 (0, 0, 0)

用 `img` 和自己做与运算（任意数 & 自己 = 自己），真正控制保留区域的是 `mask`。

## 例 4.9 提取图像中的蓝绿红区域

文件：[例4.9.py](例4.9.py)

核心流程：

```text
BGR → HSV → inRange(mask) → bitwise_and(提取)
```

```python
hsv = cv2.cvtColor(opencv, cv2.COLOR_BGR2HSV)
mask = cv2.inRange(hsv, minBlue, maxBlue)
blue = cv2.bitwise_and(opencv, opencv, mask=mask)
```

示例颜色范围：

```python
minBlue  = np.array([110, 50, 50])
maxBlue  = np.array([130, 255, 255])
minGreen = np.array([ 50, 50, 50])
maxGreen = np.array([ 70, 255, 255])
minRed   = np.array([  0, 50, 50])
maxRed   = np.array([ 30, 255, 255])
```

**非目标区域一律变成黑色**，不管原本是什么颜色（白色、灰色、其他颜色），都不会显示。S 和 V 设下限是为了排除过灰或过暗的像素（这些像素的 H 值不稳定）。

## 例 4.10 提取肤色区域

文件：[例4.10.py](例4.10.py)

核心代码：

```python
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
h, s, v = cv2.split(hsv)

hueMask = cv2.inRange(h, 5, 170)
satMask = cv2.inRange(s, 25, 166)
mask = hueMask & satMask
roi = cv2.bitwise_and(img, img, mask=mask)
```

**分别对 H 和 S 通道做范围筛选**，再用 `&`（按位与）合并两个掩码。两个条件同时满足才保留。

## 例 4.11 调整 V 通道实现艺术效果

文件：[例4.11.py](例4.11.py)

核心代码：

```python
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
h, s, v = cv2.split(hsv)
v[:, :] = 128                     # 把所有像素明度统一设为 128
newHSV = cv2.merge([h, s, v])
art = cv2.cvtColor(newHSV, cv2.COLOR_HSV2BGR)
```

V 通道控制亮度。固定 V 值 + 保留原图的 H 和 S → 产生类似艺术化的效果。修改 HSV 后必须转回 BGR 才能用 imshow 正常显示。

## 例 4.12 分析 alpha 通道

文件：[例4.12.py](例4.12.py)

核心代码：

```python
bgra = cv2.cvtColor(img, cv2.COLOR_BGR2BGRA)   # BGR → BGRA，A 默认 255
b, g, r, a = cv2.split(bgra)                    # 拆出 alpha 通道
a[:, :] = 125                                    # 改透明度
bgra = cv2.merge([b, g, r, a])                   # 合并回去
```

| Alpha 值 | 效果 |
|----------|------|
| 0 | 完全透明 |
| 125 | 半透明（约 49%） |
| 255 | 完全不透明（默认值） |

修改 alpha 不会改变 B、G、R 的颜色值，只影响透明度。

cv2.cvtColor(src, code)                  # 色彩空间转换

## 常用转换常量

| 常量 | 含义 |
|------|------|
| `cv2.COLOR_BGR2GRAY` | BGR → 灰度 |
| `cv2.COLOR_GRAY2BGR` | 灰度 → BGR（复制，非还原） |
| `cv2.COLOR_BGR2RGB` | BGR → RGB（交换通道0和2） |
| `cv2.COLOR_RGB2BGR` | RGB → BGR（交换通道0和2） |
| `cv2.COLOR_BGR2HSV` | BGR → HSV |
| `cv2.COLOR_HSV2BGR` | HSV → BGR |
| `cv2.COLOR_BGR2BGRA` | BGR → BGRA（追加 alpha=255） |

## 本章易错点

- OpenCV 默认是 **BGR**，不是 RGB；`imshow()` 按 BGR 解释，显示 RGB 图时颜色会反。
- `GRAY2BGR` 只是复制通道，**不是恢复彩色**，颜色信息在 BGR→GRAY 时已永久丢失。
- HSV 中 H 在 OpenCV 是 **0~180**，不是理论上的 0~360。
- 颜色提取要同时限制 **H、S、V**，否则容易误选黑色、白色或灰色区域。
- `mask` 作为函数参数时必须是**单通道 8 位数组**。
- alpha 通道的透明效果不能在 `imshow()` 中直接观察，需保存为 PNG。
- 常见拼写错误：`cvtColer` → `cvtColor`，`size[5,5]` → `size=[5,5]`。
- 子目录脚本运行时注意图片路径。

## 一句话总结

第 4 章的主线：理解不同色彩空间 → 用 `cvtColor()` 转换 → 颜色提取标准流程为 `BGR → HSV → inRange → mask → bitwise_and`。
