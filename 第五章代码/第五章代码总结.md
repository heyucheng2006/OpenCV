# 第五章代码总结

本章代码围绕“几何变换”展开，核心目标是理解：几何变换不是直接改颜色，而是改变像素位置。OpenCV 中常用的几何变换包括缩放、翻转、仿射变换、透视变换和重映射。

## 1. 缩放 resize

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例5.1.py` | 用小数组观察 `dsize` 和 `shape` 的顺序差异 |
| `例5.2.py` | 用 `dsize` 指定目标图像大小 |
| `例5.3.py` | 用 `fx`、`fy` 指定缩放比例 |

核心代码：

```python
rst = cv2.resize(img, (new_width, new_height))
rst = cv2.resize(img, None, fx=2, fy=0.5)
```

最重要的顺序区别：

```text
img.shape[:2]  -> (rows, cols)  -> (高, 宽)
dsize          -> (width, height) -> (宽, 高)
```

所以把 `img.shape[:2]` 直接传给 `resize()` 的 `dsize`，行列会反过来。

例 5.2 的写法是正确的：

```python
rows, cols = img.shape[:2]
size = (int(cols * 0.9), int(rows * 0.5))
rst = cv2.resize(img, size)
```

这里先从 `shape` 中按“行、列”读出 `rows, cols`，再按 `resize()` 要求的“宽、高”组装成 `(cols, rows)`。一旦 `size` 作为第二个参数传进 `resize()`，OpenCV 就会把它解释为 `(目标宽度, 目标高度)`。

例 5.3 不直接指定目标尺寸，而是用比例缩放：

```python
rst = cv2.resize(img, None, fx=2, fy=0.5)
```

其中 `fx` 控制 x 方向，也就是宽度/列数；`fy` 控制 y 方向，也就是高度/行数。可以记成：例 5.2 是“我要变成多大”，例 5.3 是“我要按比例变大或变小”。

常用插值：

| 插值方式 | 常见用途 |
|----------|----------|
| `cv2.INTER_AREA` | 缩小图像效果通常较好 |
| `cv2.INTER_LINEAR` | 默认方式，速度和效果均衡 |
| `cv2.INTER_CUBIC` | 放大图像效果较好，但速度较慢 |

## 2. 翻转 flip

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例5.4.py` | 使用 `cv2.flip()` 完成三种翻转 |

核心代码：

```python
x = cv2.flip(img, 0)    # 绕 x 轴翻转，上下翻转
y = cv2.flip(img, 1)    # 绕 y 轴翻转，左右翻转
xy = cv2.flip(img, -1)  # x 轴和 y 轴同时翻转
```

参数规律：

| `flipCode` | 含义 |
|------------|------|
| `0` | 绕 x 轴翻转，也就是上下翻转 |
| 正数 | 绕 y 轴翻转，也就是左右翻转 |
| 负数 | 绕 x 轴、y 轴同时翻转 |

需要注意：`cv2.flip(img, 0)` 只是上下翻转，不等价于整张图旋转 180 度；`cv2.flip(img, -1)` 同时上下、左右翻转，效果才等价于旋转 180 度。

`cv2.flip()` 本身没有 `mask=` 参数。如果只翻转矩形区域，优先使用 ROI：

```python
roi = img[100:400, 200:500]
img[100:400, 200:500] = cv2.flip(roi, 1)
```

如果要翻转不规则区域，可以先得到整图翻转结果，再用第 3 章的 mask 方法合成：

```python
flipped = cv2.flip(img, 1)
part_flip = cv2.bitwise_and(flipped, flipped, mask=mask)
part_origin = cv2.bitwise_and(img, img, mask=cv2.bitwise_not(mask))
result = cv2.add(part_origin, part_flip)
```

## 3. 仿射变换 warpAffine

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例5.5.py` | 自定义矩阵实现平移 |
| `例5.6.py` | 用 `getRotationMatrix2D()` 实现旋转 |
| `例5.7.py` | 用三个点生成复杂仿射矩阵 |

仿射变换使用 2x3 矩阵：

```python
dst = cv2.warpAffine(img, M, (width, height))
```

平移矩阵：

```python
M = np.float32([[1, 0, x], [0, 1, y]])
move = cv2.warpAffine(img, M, (width, height))
```

其中 `x` 控制水平方向（向右为正），`y` 控制垂直方向（向下为正）。

**平移矩阵的结构原理**：仿射变换矩阵是 2×3 的，对于每个像素 `(px, py)`：

```
new_x = 1·px + 0·py + x  =  px + x
new_y = 0·px + 1·py + y  =  py + y
```

前两列 `[[1, 0], [0, 1]]` 是单位矩阵，表示不做旋转和缩放；第三列 `[x, y]` 就是平移量。**纯平移时矩阵形式是固定的，只改动 x 和 y 两个数字即可。**

旋转矩阵：

```python
M = cv2.getRotationMatrix2D((width / 2, height / 2), 45, 0.6)
rotate = cv2.warpAffine(img, M, (width, height))
```

参数含义：

| 参数 | 含义 |
|------|------|
| `center` | 旋转中心 |
| `angle` | 旋转角度，**正数 = 逆时针，负数 = 顺时针** |
| `scale` | 缩放比例 |

角度正负约定：遵循数学坐标系（X 轴向右、Y 轴向上），正角度从 X 轴正方向逆时针转动。OpenCV 内部已对图像坐标系（Y 轴朝下）做了处理，所以直观好记：**正的就是逆着来。**

**复杂仿射（三点映射）**：

```python
p1 = np.float32([[0, 0], [cols - 1, 0], [0, rows - 1]])
p2 = np.float32([[0, rows * 0.33], [cols * 0.85, rows * 0.25], [cols * 0.15, rows * 0.7]])
M = cv2.getAffineTransform(p1, p2)
dst = cv2.warpAffine(img, M, (cols, rows))
```

**为什么恰好需要 3 个点？** 仿射变换矩阵是 2×3，共有 6 个未知数 `(a, b, c, d, tx, ty)`。1 个点对提供 2 个方程（x 和 y），3 个点对刚好提供 6 个方程，能唯一确定矩阵。仿射变换能保持直线和平行关系：直线还是直线，平行线还是平行线，但角度和距离可以改变。

## 4. 透视变换 warpPerspective

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例5.8.py` | 用四个点生成透视矩阵 |

核心代码：

```python
M = cv2.getPerspectiveTransform(pts1, pts2)
dst = cv2.warpPerspective(img, M, (cols, rows))
```

**数学原理——齐次坐标与透视除法**：

透视变换使用 **3×3 矩阵**，通过齐次坐标运算：

```
┌      ┐   ┌         ┐ ┌   ┐
│  x'  │   │ a  b  c │ │ x │
│  y'  │ = │ d  e  f │ │ y │
│  w'  │   │ g  h  1 │ │ 1 │
└      ┘   └         ┘ └   ┘
```

最终实际坐标需要除以 `w'`（**透视除法**）：

```python
x_out = x' / w'
y_out = y' / w'
```

展开后的公式：

```
x_out = (a·x + b·y + c) / (g·x + h·y + 1)
y_out = (d·x + e·y + f) / (g·x + h·y + 1)
```

**关键**：分母里有了 `gx + hy + 1`。不同的像素点除以不同的 w'，离"近"的像素被放大，离"远"的像素被缩小——这就是**近大远小**的来源，也是仿射做不到的（仿射的分母恒为 1）。

**为什么需要 4 个点？** 透视矩阵是 3×3 = 9 个未知数，但矩阵有**尺度不变性**（整体缩放不影响结果），所以通常固定 i=1，剩下 8 个自由度。1 个点对提供 2 个方程，4 个点对 = 8 个方程，刚好解出。

**仿射与透视的本质区别**：

| 对比维度 | 仿射（warpAffine） | 透视（warpPerspective） |
|----------|-------------------|------------------------|
| 点数 | 3 对点 | **4 对点** |
| 矩阵 | 2×3（6 个未知数） | **3×3**（8 个自由度） |
| 函数 | `getAffineTransform` | `getPerspectiveTransform` |
| 执行 | `warpAffine` | `warpPerspective` |
| 平行线 | 保持平行 | **可以不平行（汇聚消失）** |
| 线段比例 | 保持不变 | **可以变化（近大远小）** |
| 矩形 → 平行四边形 | 可以 | 可以 |
| 矩形 → 任意四边形 | **不能** | 可以 |
| 典型用途 | 旋转、平移、缩放、错切 | 文档扫描矫正、鸟瞰图 |

```
仿射（3点）                     透视（4点）
  原图                           原图
  ┌────┐                        ┌────┐
  │    │                        │ ╲  │
  │    │                        │  ╲ │  (侧拍，左窄右宽)
  │    │                        │   ╲│
  └────┘                        └────┘

  结果                           结果
    ╱────╲                       ┌──────┐
   ╱      ╲  ← 平行线仍平行      │      │
   ╲      ╱                     │      │  ← 平行线恢复平行
    ╲────╱                      │      │    完全矫正
                                 └──────┘
  歪斜能修，但修不"正"           透视的歪斜也能修回来
```

例 5.8 的效果就是把原图上不规则的四边形"拽"成一个规整矩形，相当于从正面俯拍的角度矫正。四个目标点围成矩形——这就是**透视矫正（Rectification）**的典型做法。

### 5.1 函数签名与核心概念

```python
dst = cv2.remap(src, map1, map2, interpolation,
                dst=None, borderMode=None, borderValue=None)
```

| 参数 | 含义 |
|------|------|
| `src` | 原图 |
| `map1` | x 方向映射表（或双通道合并表） |
| `map2` | y 方向映射表（双通道模式下填 None） |
| `interpolation` | 插值方式 |
| `borderMode` | 越界时的处理方式 |
| `borderValue` | 越界时的填充颜色 |

---

### 5.2 核心原理：反向映射

`remap` 采用**反向映射（Inverse Mapping）**：对于输出图 `rst` 上每个位置 `(i, j)`，去查映射表得到源坐标，然后去原图采样。

```python
# 伪代码：remap 内部做的事
for i in range(dst_rows):
    for j in range(dst_cols):
        src_x = mapx[i, j]   # 去原图哪一列
        src_y = mapy[i, j]   # 去原图哪一行
        dst[i, j] = interpolate(src, src_x, src_y)
```

**关键理解**：`mapx[i, j]` 不是"把原图 (i,j) 的像素搬到输出图"，而是"输出图 (i,j) 去原图的 `(mapx[i,j], mapy[i,j])` 取像素"。方向是反的。

---

### 5.3 为什么 mapx/mapy 必须是 `np.float32`

坐标不一定落在整数像素上。比如要缩小一半：

```python
mapx[i, j] = j * 2.5   # 不是整数
```

`src_x = 2.5` 表示在原图列 2 和列 3 之间，小数部分决定插值权重。如果用 `uint8` 会截掉小数，只能做最近邻采样，无法做双线性插值。`float32` 精度够用、体积合适，是标准选择。

---

### 5.4 两种传参方式

```python
# 方式一：分开传（mapx + mapy），更直观
rst = cv2.remap(img, mapx, mapy, cv2.INTER_LINEAR)

# 方式二：合并传（双通道 map1），把 x 和 y 放到两个通道里
map_xy = np.stack([mapx, mapy], axis=-1)   # shape: (h, w, 2)
rst = cv2.remap(img, map_xy, None, cv2.INTER_LINEAR)
```

---

### 5.5 插值方式

当 `mapx/mapy` 指向的坐标不是整数时，需要插值：

| 标志 | 方式 | 说明 |
|------|------|------|
| `cv2.INTER_NEAREST` | 最近邻 | 四舍五入取最近整数像素，有锯齿 |
| `cv2.INTER_LINEAR` | 双线性 | 周围 2×2 加权平均，**最常用** |
| `cv2.INTER_CUBIC` | 双三次 | 周围 4×4 拟合，更平滑但更慢 |
| `cv2.INTER_LANCZOS4` | Lanczos | 周围 8×8，质量最高 |

例：`src_x=2.3, src_y=0.0`：
- `INTER_NEAREST` → 取 `img[0, 2]`
- `INTER_LINEAR` → `img[0,2]×0.7 + img[0,3]×0.3 = 加权结果`

---

### 5.6 越界处理

当 `mapx/mapy` 指向原图之外时：

| 标志 | 行为 |
|------|------|
| `cv2.BORDER_CONSTANT` | 用固定颜色填充（默认黑色），配合 `borderValue` |
| `cv2.BORDER_REPLICATE` | 用最近的边界像素复制 |
| `cv2.BORDER_REFLECT` | 镜像反射 |
| `cv2.BORDER_WRAP` | 循环重复 |

---

### 5.7 逐像素计算示例（例 5.9）

```python
img = np.random.randint(0, 256, size=[4, 5], dtype=np.uint8)
mapx = np.ones(img.shape, np.float32) * 3   # 所有位置都是 3
mapy = np.ones(img.shape, np.float32) * 0   # 所有位置都是 0
rst = cv2.remap(img, mapx, mapy, cv2.INTER_LINEAR)
```

计算过程：

```
rst[0, 0] → 查表 src_x=3.0, src_y=0.0 → 整数坐标，直接取 img[0, 3] = 142
rst[0, 1] → 查表 src_x=3.0, src_y=0.0 → 还是 img[0, 3] = 142
...
20 个输出像素全部指向同一个源坐标 → 结果是一张纯色图，全是 142
```

**例 5.9 是极端特例**，正常使用时 mapx 和 mapy 里每个位置的值各不相同，每个输出像素去不同位置抄——这样才能实现翻转、缩放、扭曲等效果。

---

### 5.8 常用映射模式

**恒等映射（不改变图像，例 5.10）**：

```python
mapx[i, j] = j      # 横坐标不变
mapy[i, j] = i      # 纵坐标不变
# 每个像素抄自己 → 原封不动
```

**垂直翻转 / 绕 x 轴翻转（例 5.12）**：

```python
mapx[i, j] = j              # 横坐标不变
mapy[i, j] = rows - 1 - i   # 纵坐标翻转
# i=0 → 取原图最底行；i=rows-1 → 取原图最顶行
```

**水平翻转 / 绕 y 轴翻转**：

```python
mapx[i, j] = cols - 1 - j   # 横坐标翻转
mapy[i, j] = i              # 纵坐标不变
```

**同时水平+垂直翻转**：

```python
mapx[i, j] = cols - 1 - j
mapy[i, j] = rows - 1 - i
# 效果等价于旋转 180 度
```

**x、y 轴互换（转置）**：

```python
mapx[i, j] = i
mapy[i, j] = j
# 行变列、列变行
```

**局部放大（例 5.20）**：只对原图中间区域重新映射，通过调整坐标间距实现放大效果；其余区域指向 (0,0) 变纯色。

---

### 5.9 remap 的地位

```
warpAffine       = 算 mapx/mapy（仿射公式） + remap
warpPerspective  = 算 mapx/mapy（透视公式） + remap
remap            = 你自己随心所欲定义映射关系
```

`remap` 是 OpenCV 里最底层的几何变换函数，给了最大的自由度。前面的 `warpAffine`、`warpPerspective`、`warpPolar` 本质都是帮你自动生成映射表然后调 `remap` 执行。

如果 `mapx` 或 `mapy` 指向了原图外的位置，默认会用边界值填充，通常看到的是黑色或 0。

## 本章易错点

- `shape` 是 `(高, 宽)`，`dsize` 是 `(宽, 高)`。
- 从 `shape` 中读出来是 `rows, cols`，传给 `resize()` 时通常要写成 `(cols, rows)`。
- `fx` 控制水平方向缩放，也就是列数；`fy` 控制垂直方向缩放，也就是行数。
- `cv2.flip(img, 0)` 只是上下翻转；`cv2.flip(img, -1)` 才等价于旋转 180 度。
- `cv2.flip()` 没有 `mask=` 参数；局部矩形翻转用 ROI，不规则区域翻转用”整图翻转 + mask 合成”。
- `warpAffine()` 和 `warpPerspective()` 的 `dsize` 也都是 `(width, height)`。
- `getRotationMatrix2D()` 的旋转中心应该写成 `(width / 2, height / 2)`，不要把宽高写反。
- 旋转角度：正数 = 逆时针，负数 = 顺时针。`例5.6.py` 中用的是 `-45`（顺时针 45°）。
- 仿射变换用 3 对点（因为 2×3 矩阵有 6 个未知数），透视变换用 4 对点（因为 3×3 矩阵有 8 个自由度）。
- 仿射变换保持平行线不变，透视变换可以让平行线汇聚（近大远小效果）。
- `remap()` 中 `mapx` 是列号，`mapy` 是行号；它是**反向映射**：问的是”目标位置去原图哪里取值”，不是”原图的像素搬到输出图哪里”。
- `remap()` 的 `mapx` 和 `mapy` **必须用 `np.float32`**，因为坐标可能带小数（插值需要）。用 `uint8` 会报错或截断小数。
- `remap()` 中 `mapx=3, mapy=0` 表示去原图 `img[0, 3]`。注意数组访问是 `img[行, 列]`，而 map 是 `(x=列, y=行)`，顺序刚好相反。
- `mapx`、`mapy` 和输出图三者尺寸完全一致。
- 教材里的 `itemset()` 在新版 NumPy 中不可用，直接写 `mapx[i, j] = value` 更稳。
- 子目录脚本运行时注意图片路径；本章示例按工作区根目录运行，读取的是 `001.bmp`。

## 一句话总结

第 5 章的主线：先理解像素坐标如何变化，再选择对应函数。简单缩放用 `resize()`，简单翻转用 `flip()`，平移旋转和三点映射用 `warpAffine()`，四点透视校正用 `warpPerspective()`，完全自定义像素来源用 `remap()`。

深入理解三个层次：
1. **手动写矩阵** — 平移、缩放、旋转，自己构建 2×3 矩阵 → `warpAffine`
2. **点对算矩阵** — 仿射 3 对点 → `getAffineTransform`；透视 4 对点 → `getPerspectiveTransform`
