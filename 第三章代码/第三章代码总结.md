# 第三章代码总结

本目录代码围绕第三章”图像运算”展开，核心目标是理解：图像运算本质上是在对像素值进行算术运算或按位逻辑运算。很多更复杂的图像处理任务，例如图像融合、掩模提取、位平面分解、图像加密、数字水印，都是由这些基础运算组合出来的。

`cv2.imread()` 第二个参数控制读取模式：

| 值 | 常量 | 含义 |
|----|------|------|
| `0` | `cv2.IMREAD_GRAYSCALE` | 灰度，单通道 |
| `1` | `cv2.IMREAD_COLOR` | 彩色（默认），三通道 BGR |
| `-1` | `cv2.IMREAD_UNCHANGED` | 原样，含 alpha 通道（如 PNG 透明） |

BMP 不支持透明通道，所以对 BMP 用 `1` 和 `-1` 没区别。

## 1. 图像加法运算

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例3.1+3.2.py` | 对比 NumPy 的 `+` 和 OpenCV 的 `cv2.add()` |
| `例3.3.py` | 将图像与自身相加，观察取模加法和饱和加法的效果 |

两种加法的核心区别：

```python
result1 = img1 + img2
result2 = cv2.add(img1, img2)
```

`+` 是 NumPy 数组加法，对 `uint8` 图像会发生取模：

```text
200 + 100 = 300
300 % 256 = 44
```

`cv2.add()` 是 OpenCV 图像加法，会进行饱和处理：

```text
200 + 100 = 255
```

复习重点：

- `img1 + img2` 超过 `255` 后会回绕，亮的地方可能反而变暗。
- `cv2.add(img1, img2)` 超过 `255` 后固定为 `255`，更符合图像亮度叠加的直觉。
- 两张图像参与运算时，尺寸和类型要匹配。

## 2. 图像加权和

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例3.4.py` | 使用数组演示 `cv2.addWeighted()` 的公式 |
| `例3.5.py` | 缩放图片尺寸后进行整图加权融合 |
| `例3.6.py` | 提取两张图的 ROI，再对 ROI 进行加权融合 |

核心公式：

```text
dst = src1 * alpha + src2 * beta + gamma
```

对应代码：

```python
result = cv2.addWeighted(a, 0.3, c, 0.7, 2)
```

含义是：

```text
result = a * 0.3 + c * 0.7 + 2
```

ROI 加权融合：

```python
face1 = a[100:300, 100:300]
face2 = b[100:300, 100:300]
add = cv2.addWeighted(face1, 0.5, face2, 0.5, 4)
b[100:300, 100:300] = add
```

复习重点：

- `alpha` 和 `beta` 控制两张图的占比，谁的权重大，结果更像谁。
- `gamma` 是亮度调节量，即使不用也要写 `0`。
- 整图融合前要保证两张图大小一致，可以使用 `cv2.resize()`。
- ROI 融合时，两个 ROI 的形状必须一致。

## 3. 按位逻辑运算

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例3.7.py` | 使用 5x5 数组演示与、或、非、异或 |
| `例3.8.py` | 对真实图像和三通道掩模做位运算 |

常用函数：

```python
cv2.bitwise_and(a, b)  # 按位与
cv2.bitwise_or(a, b)   # 按位或
cv2.bitwise_not(a)     # 按位取反
cv2.bitwise_xor(a, b)  # 按位异或
```

直观理解：

| 运算 | 规则 | 常见用途 |
|------|------|----------|
| 与 | 两位都是 1 才为 1 | 掩模提取、保留局部 |
| 或 | 只要有一个 1 就为 1 | 合并信息 |
| 非 | 0 和 1 互换 | 反色、反转掩模 |
| 异或 | 相同为 0，不同为 1 | 加密、解密、找差异 |

`例3.7.py` 中的掩模数组：

```python
b = np.zeros((5, 5), dtype=np.uint8)
b[0:3, 0:3] = 255
b[4, 4] = 255
```

含义是：左上角 `3x3` 和右下角一个点为 `255`，其他位置为 `0`。

复习重点：

- `任意数 & 0 = 0`。
- `任意数 & 255 = 任意数本身`。
- `bitwise_not()` 对 8 位灰度图近似等价于 `255 - img`。
- 异或满足 `A xor B xor B = A`，这是图像加密和解密的基础。

## 4. 掩模 mask

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例3.9.py` | 在 `cv2.add()` 中使用 `mask` 参数 |
| `例3.11.py` | 使用单通道 mask 控制彩色图像的局部保留 |

掩模的概念：

```text
mask 非 0 的地方参与运算
mask 为 0 的地方结果为 0
```

在 `cv2.add()` 中使用 mask：

```python
img3 = cv2.add(img1, img2, mask=mask)
```

在按位与中使用 mask：

```python
mask = np.zeros(a.shape[:2], dtype=np.uint8)
mask[100:400, 200:400] = 255
c = cv2.bitwise_and(a, a, mask=mask)
```

为什么是 `a` 和 `a` 自己做与运算：

```text
任意数 & 自己 = 自己
```

真正控制保留区域的是 `mask`。

复习重点：

- `mask` 参数必须是 8 位单通道数组，形状通常是 `(height, width)`。
- 三通道图像可以作为 `cv2.bitwise_and(a, b)` 的参数，但不能直接作为 `mask=` 参数。
- `a.shape` 的顺序是 `(height, width, channels)`，变量名不要误写成宽、高、通道。
- mask 判断的是"非零"：`1`、`128`、`255` 效果相同，都被视为参与运算的区域。只有 `0` 表示跳过。

## 5. 图像与数值的运算

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例3.12.py` | 演示图像与图像、图像与数值、数值与图像的加法 |

关键写法：

```python
img3 = cv2.add(img1, img2)
img4 = cv2.add(img1, 6)
img5 = cv2.add(6, img2)
```

含义：

- `cv2.add(img1, img2)`：两幅图像对应像素相加。
- `cv2.add(img1, 6)`：图像每个像素都加 `6`。
- `cv2.add(6, img2)`：数值和图像相加。

复习重点：

- 给图像加固定数值可以整体提高亮度。
- 使用 `cv2.add()` 时仍然是饱和加法，超过 `255` 会固定为 `255`。

## 6. 位平面分解

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例3.13.py` | 提取灰度图像 8 个位平面，并做阈值处理显示 |

8 位灰度图的每个像素可以拆成 8 个二进制位：

```text
第 0 位：最低有效位，影响最小
第 7 位：最高有效位，影响最大
```

构造提取矩阵：

```python
x = np.zeros((r, c, 8), dtype=np.uint8)
for i in range(8):
    x[:, :, i] = 2 ** i
```

提取第 `i` 个位平面：

```python
r[:, :, i] = cv2.bitwise_and(a, x[:, :, i])
```

阈值处理：

```python
mask = r[:, :, i] > 0
r[:, :, i][mask] = 255
```

为什么要阈值处理：

```text
提取第 3 位时，结果只有 0 或 8。
8 在灰度图里太暗，显示不明显。
把所有非 0 值改成 255 后，位平面才能清楚显示为黑白图。
```

复习重点：

- 位平面分解依赖按位与运算。
- 低位平面通常更杂乱，高位平面通常更接近原图结构。
- 阈值处理在这里主要是为了显示清楚。

## 7. 图像加密和解密

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例3.14.py` | 使用随机密钥图像进行异或加密和解密 |

关键写法：

```python
key = np.random.randint(0, 256, size=[r, c], dtype=np.uint8)
encryption = cv2.bitwise_xor(a, key)
decryption = cv2.bitwise_xor(encryption, key)
```

核心原理：

```text
A xor K xor K = A
```

也就是：同一把密钥异或两次，可以还原原图。

概念理解：

异或加密可以把原图理解成 `A`，把随机密钥图像理解成 `K`。第一次异或时，`K` 会把 `A` 的二进制位打乱，得到看起来像噪声的加密图；第二次再用同一个 `K` 异或，之前被翻转过的位会被翻转回来，所以恢复成原图。这里最关键的不是“随机”，而是“同一个 key 必须重复使用”。

从单个二进制位看，异或的规律是：

```text
0 xor 0 = 0
0 xor 1 = 1
1 xor 0 = 1
1 xor 1 = 0
```

如果 `key` 的某一位是 `0`，原图这一位不会改变：

```text
0 xor 0 = 0
1 xor 0 = 1
```

如果 `key` 的某一位是 `1`，原图这一位会被翻转：

```text
0 xor 1 = 1
1 xor 1 = 0
```

所以，密钥图像 `key` 的作用就是决定每一个像素的每一个二进制位是否翻转。解密时再次使用同一个 `key`，该翻转的位再翻转一次，就回到原值。

可以把它想成一个可逆开关：

```text
原图 A --xor key--> 加密图
加密图 --xor 同一个 key--> 原图 A
```

对应到代码：

```python
encryption = cv2.bitwise_xor(a, key)
decryption = cv2.bitwise_xor(encryption, key)
```

第一行得到加密图，第二行还原。这里 `key` 的尺寸必须和 `a` 一样，因为异或是逐像素、逐位进行的。

复习重点：

- 密钥图像 `key` 必须和原图尺寸一致。
- 加密结果看起来像随机图。
- 解密时必须使用同一个 `key`。

## 8. 数字水印

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例3.17.py` | 将水印嵌入载体图像最低位，并提取出来 |

嵌入思路：

```text
1. 把水印图像二值化为 0 和 1。
2. 清除载体图像最低位。
3. 把水印写入载体图像最低位。
```

概念理解：

数字水印利用的是“最低位对图像视觉影响很小”这个特点。一个 8 位灰度像素由 8 个二进制位组成，最高位权重最大，最低位权重最小。修改最低位最多只会让像素值变化 `1`，人眼通常不容易察觉；但计算机可以通过按位与把最低位重新提取出来。

例如一个像素值：

```text
200 = 1100 1000
```

如果只修改最低位：

```text
1100 1000 -> 1100 1001
200       -> 201
```

像素值只变化了 `1`，视觉上几乎没有区别。数字水印正是利用这个空间，把水印信息藏在最低位里。

所以水印流程可以理解成：

```text
载体图像：保留高 7 位，最低位清零
水印图像：压缩成 0/1
嵌入图像：高 7 位来自载体，最低位来自水印
```

这就是为什么代码中会用 `254` 和 `1`：

```text
254 = 1111 1110  # 清除最低位
1   = 0000 0001  # 提取最低位
```

嵌入时：

```python
t254 = np.ones((r, c), dtype=np.uint8) * 254
aH7 = cv2.bitwise_and(a, t254)
e = cv2.bitwise_or(watermark, aH7)
```

这三行可以分成两步理解：

1. `aH7 = cv2.bitwise_and(a, t254)`：把载体图像的最低位清零，只保留高 7 位。
2. `e = cv2.bitwise_or(watermark, aH7)`：把已经变成 `0/1` 的水印写进最低位。

提取时：

```python
t1 = np.ones((r, c), dtype=np.uint8)
wm = cv2.bitwise_and(e, t1)
wm[wm > 0] = 255
```

这里 `t1` 的二进制是 `0000 0001`，只会保留嵌入图像的最低位。提取出来后值只有 `0` 和 `1`，为了显示清楚，再把 `1` 改成 `255`。

关键代码：

```python
t254 = np.ones((r, c), dtype=np.uint8) * 254
aH7 = cv2.bitwise_and(a, t254)
e = cv2.bitwise_or(watermark, aH7)
```

其中：

```text
254 = 1111 1110
```

所以：

```python
aH7 = cv2.bitwise_and(a, t254)
```

会保留载体图像的高 7 位，把最低位清零。

提取水印：

```python
t1 = np.ones((r, c), dtype=np.uint8)
wm = cv2.bitwise_and(e, t1)
wm[wm > 0] = 255
```

复习重点：

- 最低位对图像视觉影响小，适合隐藏水印。
- 水印嵌入前要转成 `0` 和 `1`。
- 提取后要把 `1` 转成 `255`，方便显示。
- 水印图和载体图尺寸可能不同，嵌入前需要用 `cv2.resize()` 将水印缩放到和载体一致，否则 `bitwise_or` 会因形状不匹配报错。

```python
watermark = cv2.resize(watermark, (a.shape[1], a.shape[0]))
```

## 9. 脸部打码及解码

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例3.18.py` | 使用 mask、key 和异或实现局部加密与还原 |

核心流程：

```text
1. 构造 mask，指定需要加密的区域。
2. 生成随机 key。
3. 原图与 key 异或，得到加密图。
4. 用 mask 只保留加密区域。
5. 用 1-mask 保留未加密区域。
6. 把两部分相加，得到局部打码图。
7. 使用同一个 key 和 mask 还原加密区域。
```

概念理解：

脸部打码及解码其实是“局部异或加密”。它不是把整张图都加密，而是用 `mask` 把图像分成两块：

```text
mask = 1 的区域：需要打码/加密
mask = 0 的区域：保持原样
```

处理时先得到整张图的异或加密结果，再用 `mask` 只取出需要加密的区域；同时用 `1-mask` 从原图中取出不需要加密的区域。最后把两部分相加，就得到“只有局部被打码”的图像。

还原时也是同一个思想：先用同一个 `key` 把加密区域解回来，再用 `1-mask` 保留没有动过的区域，最后重新拼合。

这里最绕的是 `mask` 和 `1-mask`：

```text
mask      表示要处理的区域
1 - mask  表示不要处理的区域
```

如果 `mask` 是：

```text
0 0 0
0 1 1
0 1 1
```

那么 `1-mask` 就是：

```text
1 1 1
1 0 0
1 0 0
```

二者刚好互补。一个负责取出脸部区域，一个负责取出非脸部区域。

可以把它看成一次区域拼图：

```text
打码图 = 加密脸部区域 + 原始非脸部区域
还原图 = 解密脸部区域 + 原始非脸部区域
```

对应到代码的分解过程：

```python
aXorKey = cv2.bitwise_xor(a, key)
encryption = cv2.bitwise_and(aXorKey, mask)
noface = cv2.bitwise_and(a, (1 - mask) * 255)
maskface = encryption + noface
```

含义是：

1. `aXorKey`：先把整张图都异或加密。
2. `encryption`：用 `mask` 只保留加密后的脸部区域。
3. `noface`：用 `(1-mask)` 保留原图中非脸部区域。
4. `maskface`：把“加密脸部”和“原始非脸部”拼回一张图。

还原时：

```python
extractOriginal = cv2.bitwise_xor(maskface, key)
extractFace = cv2.bitwise_and(extractOriginal, mask * 255)
noface2 = cv2.bitwise_and(maskface, (1 - mask) * 255)
extracta = noface2 + extractFace
```

可以理解为：

1. 先用同一个 `key` 尝试解密。
2. 只取出被 mask 标记的脸部区域。
3. 非脸部区域本来没被加密，直接从 `maskface` 里取回来。
4. 两部分相加，恢复完整图像。

关键代码：

```python
mask = np.zeros((r, c), dtype=np.uint8)
mask[100:400, 200:400] = 1

key = np.random.randint(0, 256, size=[r, c], dtype=np.uint8)
aXorKey = cv2.bitwise_xor(a, key)
encryption = cv2.bitwise_and(aXorKey, mask)
noface = cv2.bitwise_and(a, (1 - mask) * 255)
maskface = encryption + noface
```

还原：

```python
extractOriginal = cv2.bitwise_xor(maskface, key)
extractFace = cv2.bitwise_and(extractOriginal, mask * 255)
noface2 = cv2.bitwise_and(maskface, (1 - mask) * 255)
extracta = noface2 + extractFace
```

复习重点：

- `mask` 中的 `1` 用来参与局部保留，显示时常乘以 `255`。
- `(1 - mask)` 表示反向区域。
- 异或加密必须使用同一个 `key` 才能还原。
- 加密区域和未加密区域可以通过 mask 拆开，再相加合成。

## 10. 本章代码总复习

最常用的代码模式：

```python
import cv2
import numpy as np

img = cv2.imread("001.bmp", 0)

added = cv2.add(img, 30)

mask = np.zeros(img.shape[:2], dtype=np.uint8)
mask[100:400, 200:400] = 255
roi = cv2.bitwise_and(img, img, mask=mask)

key = np.random.randint(0, 256, img.shape[:2], dtype=np.uint8)
encrypted = cv2.bitwise_xor(img, key)
restored = cv2.bitwise_xor(encrypted, key)

cv2.imshow("img", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

最容易出错的点：

- `+` 和 `cv2.add()` 对超过 `255` 的处理不同：前者取模，后者饱和。
- `cv2.addWeighted()` 的两张图或两个 ROI 必须大小、类型一致。
- `mask=` 参数必须是单通道 `uint8`，不是三通道图像。
- `mask` 用作显示时常用 `0/255`，用作逻辑区域时有时用 `0/1`，要分清。
- 位平面提取后如果不做阈值处理，低位结果会很暗，不便观察。
- 异或加密能还原的前提是使用同一个密钥图像。
- VS Code 默认以工作区根目录运行脚本，所以直接写 `"001.bmp"` 即可。如果需要在任意目录都能正确读取图片，用 `os.path` 基于脚本文件位置拼接路径：

```python
import os
base = os.path.dirname(os.path.abspath(__file__))
img = cv2.imread(os.path.join(base, "..", "001.bmp"), 0)
```
