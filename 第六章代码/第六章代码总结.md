# 第六章代码总结

本章代码围绕“阈值处理”展开，核心目标是理解：阈值处理根据像素灰度值把图像分成不同区域，常用于前景和背景分离、二值图生成、文字/目标提取等任务。

## 2. 五种常用阈值类型

假设阈值 `thresh=127`，最大值 `maxval=255`。

| 类型 | 大于阈值的像素 | 小于或等于阈值的像素 | 直观理解 |
|------|----------------|----------------------|----------|
| `THRESH_BINARY` | 变成 255 | 变成 0 | 大的变白，小的变黑 |
| `THRESH_BINARY_INV` | 变成 0 | 变成 255 | 大的变黑，小的变白 |
| `THRESH_TRUNC` | 变成 127 | 保持原值 | 超过上限就截断 |
| `THRESH_TOZERO_INV` | 变成 0 | 保持原值 | 去掉亮的，保留暗的 |
| `THRESH_TOZERO` | 保持原值 | 变成 0 | 保留亮的，去掉暗的 |

对应代码：

```python
_, binary = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY)
_, binary_inv = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY_INV)
_, trunc = cv2.threshold(img, 127, 255, cv2.THRESH_TRUNC)
_, tozero_inv = cv2.threshold(img, 127, 255, cv2.THRESH_TOZERO_INV)
_, tozero = cv2.threshold(img, 127, 255, cv2.THRESH_TOZERO)
```

二值化和反二值化会把结果压成 `0/255` 两种值，适合做黑白分割。`TRUNC` 和 `TOZERO` 系列不会完全二值化，会保留部分灰度层次。

## 3. 自适应阈值 adaptiveThreshold

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例6.11.py` | 比较普通阈值、自适应均值阈值和自适应高斯阈值 |

核心函数：

```python
rst = cv2.adaptiveThreshold(
    img, 255,
    cv2.ADAPTIVE_THRESH_MEAN_C,
    cv2.THRESH_BINARY,
    5, 3
)
```

参数含义：

| 参数 | 含义 |
|------|------|
| `img` | 原图，必须是 8 位单通道灰度图 |
| `255` | 最大值 |
| `adaptiveMethod` | 局部阈值计算方法 |
| `thresholdType` | 只能是 `THRESH_BINARY` 或 `THRESH_BINARY_INV` |
| `blockSize` | 邻域大小，必须是大于 1 的奇数，例如 3、5、7 |
| `C` | 从局部均值或加权均值中减去的常量 |

两种自适应方法：

| 方法 | 含义 |
|------|------|
| `cv2.ADAPTIVE_THRESH_MEAN_C` | 邻域内像素等权平均，再减去 C |
| `cv2.ADAPTIVE_THRESH_GAUSSIAN_C` | 邻域内像素按高斯权重平均，再减去 C |

普通阈值整张图只用一个固定阈值；自适应阈值会给每个像素根据周围邻域计算一个局部阈值。图像明暗不均时，自适应阈值通常保留更多细节。

## 4. Otsu 自动阈值

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例6.12.py` | 用小数组观察 Otsu 自动阈值 |
| `例6.13.py` | 比较普通二值化和 Otsu 阈值处理 |

核心代码：

```python
t, otsu = cv2.threshold(img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
```

Otsu 的特点：

- 不需要手动指定阈值，`thresh` 参数通常写 `0`。
- OpenCV 会自动寻找一个更合适的阈值。
- 返回值 `t` 是 Otsu 算法实际计算并使用的阈值。
- 常用于前景和背景灰度分布比较明显、但最佳阈值不是 127 的图像。

与普通阈值的区别：

```python
t1, thd = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY)
t2, otsu = cv2.threshold(img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
```

第一行的 `t1` 通常是 `127.0`；第二行的 `t2` 是算法自动算出来的值。

## 本章易错点

- `cv2.threshold()` 有两个返回值：第一个是阈值 `t`，第二个才是结果图 `rst`。
- `THRESH_BINARY` 的判断条件是 `src > thresh`，等于阈值时会进入“其他情况”。
- `THRESH_BINARY` 和 `THRESH_BINARY_INV` 会生成真正的二值图；`TRUNC` 和 `TOZERO` 系列会保留部分灰度值。
- `THRESH_TRUNC` 中 `maxval` 参数基本不起作用，超过阈值的像素会被设成 `thresh`。
- `adaptiveThreshold()` 的输入必须是 8 位单通道图像，所以通常用 `cv2.imread(path, 0)` 读取。
- `adaptiveThreshold()` 的 `blockSize` 必须是大于 1 的奇数。
- `adaptiveThreshold()` 的 `thresholdType` 只能是 `THRESH_BINARY` 或 `THRESH_BINARY_INV`。
- 使用 Otsu 时，`thresh` 通常写 `0`，并把 `cv2.THRESH_OTSU` 加到阈值类型里。
- Otsu 返回的 `t` 才是自动计算出的阈值，不要忽略它。
- 子目录脚本运行时注意图片路径；本章示例按工作区根目录运行，读取的是 `001.bmp`。

## 一句话总结

第 6 章的主线：固定阈值用 `threshold()`，明暗不均用 `adaptiveThreshold()`，不想手动猜阈值用 `THRESH_OTSU`。
