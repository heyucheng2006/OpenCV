# 第二章代码总结

本目录代码围绕第二章“图像处理基础”展开，核心目标是理解：OpenCV 图像本质上是 NumPy 数组，图像处理就是对数组中的像素、区域和通道进行操作。

## 1. 图像与数组

灰度图像是二维数组：

```python
img[row, col]
```

彩色图像是三维数组：

```python
img[row, col, channel]
```

OpenCV 中彩色图像通道顺序是 `BGR`：

```python
img[:, :, 0]  # B 通道
img[:, :, 1]  # G 通道
img[:, :, 2]  # R 通道
```

## 2. 图像显示的基本模式

使用 OpenCV 显示图像，必须写"三段式"：

```python
cv2.imshow("窗口标题", img)   # 1. 显示图像
cv2.waitKey(0)                # 2. 等待按键（0 = 无限等待）
cv2.destroyAllWindows()       # 3. 关闭所有窗口
```

**每行都不可省略。** 缺少 `waitKey()`，窗口会一闪而逝；缺少 `destroyAllWindows()`，窗口可能残留。

> 实操中反复出现的坑：写完 `imshow` 忘了写 `waitKey`，窗口一闪就没了。

## 3. 像素访问与修改

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例2.1.py` | 创建 8x8 灰度图像，并修改单个像素 |
| `例2.2.py` | 读取灰度图像，并用双层循环修改一个矩形区域 |
| `例2.7.py` | 使用随机二维数组模拟灰度图像，访问和修改单个元素 |
| `例2.9.py` | 读取灰度图像，修改单个像素和局部区域 |

关键写法：

```python
img = np.zeros((8, 8), dtype=np.uint8)
img[0, 3] = 255
```

这表示创建一张 8x8 的黑色灰度图，并把第 0 行第 3 列的像素改成白色。

区域修改可以用循环：

```python
for i in range(10, 100):
    for j in range(80, 100):
        img[i, j] = 0
```

也可以用更简洁的切片：

```python
img[10:100, 80:100] = 0
```

复习重点：

- 灰度图像中，`0` 通常表示黑色，`255` 通常表示白色。
- 数组索引从 `0` 开始。
- `img[row, col]` 中 `row` 是行，也就是 y 方向；`col` 是列，也就是 x 方向。

## 4. 彩色图像与通道赋值

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例2.3.py` | 分别创建纯蓝、纯绿、纯红图像 |
| `例2.4.py` | 在同一张图像中生成蓝、绿、红三个竖条 |
| `例2.12.py` | 创建随机彩色图像，并把局部区域设置为蓝色 |

关键写法：

```python
blue = np.zeros((300, 300, 3), dtype=np.uint8)
blue[:, :, 0] = 255
```

这里第 0 个通道是 B 通道，所以图像显示为蓝色。

```python
green[:, :, 1] = 255
red[:, :, 2] = 255
```

分别表示绿色和红色。

在 `例2.4.py` 中：

```python
img[:, 0:100, 0] = 255
img[:, 100:200, 1] = 255
img[:, 200:300, 2] = 255
```

含义是：

- 左侧 100 列设置 B 通道，显示为蓝色。
- 中间 100 列设置 G 通道，显示为绿色。
- 右侧 100 列设置 R 通道，显示为红色。

复习重点：

- 彩色图像数组形状一般是 `(height, width, 3)`。
- OpenCV 是 `BGR`，不是 `RGB`。
- 想设置红色，应写 `[0, 0, 255]`，不是 `[255, 0, 0]`。

## 5. 随机图像

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例2.7.py` | 创建 5x5 随机灰度数组 |
| `例2.8.py` | 创建 256x256 随机灰度图 |
| `例2.12.py` | 创建 300x300x3 随机彩色图 |
| `例2.13+14.py` | 创建随机区域覆盖原图局部，实现类似打码效果 |

关键写法：

```python
img = np.random.randint(0, 256, size=[256, 256], dtype=np.uint8)
```

生成一张随机灰度图。

```python
img = np.random.randint(0, 256, size=[300, 300, 3], dtype=np.uint8)
```

生成一张随机彩色图。

复习重点：

- `np.random.randint(0, 256, ...)` 生成的值范围是 `0` 到 `255`。
- `dtype=np.uint8` 表示像素值是 8 位无符号整数，范围正好是 `0~255`。

常见错误 — `size` 参数写成嵌套元组：

```python
# 错误：多了一层括号，变成了 (0, 256, (180,100,3))
eye = np.random.randint(0, 256, (0, 256, (180, 100, 3)))

# 正确：size 直接是 (h, w, c)
eye = np.random.randint(0, 256, (180, 100, 3))
```

## 6. 感兴趣区域 ROI

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例2.13+14.py` | 截取原图局部区域，并用随机图像覆盖另一块区域 |
| `例2.15.py` | 从一张图中截取 ROI，再复制到另一张图中 |

关键写法：

```python
face = a[0:400, 300:600]
```

表示截取：

- 第 0 到 399 行
- 第 300 到 599 列

即：

```python
roi = img[y1:y2, x1:x2]
```

复制 ROI：

```python
m = a[0:400, 300:600]
b[100:500, 400:700] = m
```

这里源区域大小和目标区域大小必须一致：

```text
源区域: 400 行 x 300 列
目标区域: 400 行 x 300 列
```

复习重点：

- ROI 本质是 NumPy 切片。
- 切片顺序是 `[y1:y2, x1:x2]`，不是 `[x1:x2, y1:y2]`。
- 赋值时，源 ROI 和目标区域的形状要一致。
- ROI 切片通常是原图视图，修改 ROI 可能会影响原图；需要独立副本时使用 `.copy()`。

## 7. 通道拆分、修改与合并

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例2.16.py` | 使用索引拆分 B、G、R 通道，并逐步清零通道 |
| `例2.17.py` | 使用 `cv2.split()` 拆分通道 |
| `例2.18.py` | 使用 `cv2.merge()` 合并通道，并对比 BGR 与 RGB 顺序 |

通过索引拆分通道：

```python
b = lena[:, :, 0]
g = lena[:, :, 1]
r = lena[:, :, 2]
```

通过函数拆分通道：

```python
b, g, r = cv2.split(lena)
```

清空某个通道：

```python
lena[:, :, 0] = 0  # 清空 B 通道
lena[:, :, 1] = 0  # 清空 G 通道
lena[:, :, 2] = 0  # 清空 R 通道
```

合并通道：

```python
bgr = cv2.merge([b, g, r])
rgb = cv2.merge([r, g, b])
```

`bgr` 和原图颜色一致；`rgb` 因为通道顺序被调换，使用 `cv2.imshow()` 显示时颜色会发生变化。

复习重点：

- 单独显示 `b`、`g`、`r` 时，它们是灰度图。
- 单通道图越亮，表示该通道分量越大。
- `cv2.imshow()` 按 OpenCV 的 BGR 顺序显示。
- **通道清零是累积的！** 例 2.16 中在同一个 `lena` 上连续清零 B→G→R，每次都在上一次基础上修改，最后一个窗口是全黑图。如果想独立看每个通道清零的效果，需要每次 `cv2.imread()` 重新读取，或者用 `.copy()` 创建副本：

```python
lena[:, :, 0] = 0          # B=0，只剩 G、R
cv2.imshow("B=0", lena)

lena = cv2.imread("...")   # 重新读取，恢复原始图像
lena[:, :, 1] = 0          # G=0，只剩 B、R
cv2.imshow("G=0", lena)
```

## 8. 图像属性

相关代码：

| 文件 | 主要内容 |
|------|----------|
| `例2.19.py` | 分别读取灰度图和彩色图，输出 `shape`、`size`、`dtype` |

关键写法：

```python
print(gray.shape)
print(gray.size)
print(gray.dtype)
```

属性含义：

| 属性 | 含义 |
|------|------|
| `shape` | 图像形状，灰度图是 `(height, width)`，彩色图是 `(height, width, channels)` |
| `size` | 数组元素总数 |
| `dtype` | 像素值数据类型，普通图像通常是 `uint8` |

灰度图：

```python
gray.shape  # (height, width)
```

彩色图：

```python
color.shape  # (height, width, 3)
```

复习重点：

- `shape` 的顺序是高、宽、通道数。
- 彩色图的 `size = height * width * 3`。
- 如果 `cv2.imread()` 路径错误，返回值是 `None`，此时访问 `img.shape` 会报错。

**防御性读取**：每次 `imread` 后都检查，避免 `NoneType` 异常：

```python
img = cv2.imread("001.bmp")
if img is None:
    print("图片读取失败，请检查文件路径")
    exit()
```

另外注意代码的运行目录：如果脚本在子目录中，图片在上级目录，要写 `"../001.bmp"`。

## 9. 本章代码总复习

最常用的代码模式：

```python
import cv2
import numpy as np

img = cv2.imread("001.bmp")

print(img.shape, img.size, img.dtype)

roi = img[y1:y2, x1:x2]

b, g, r = cv2.split(img)
merged = cv2.merge([b, g, r])

cv2.imshow("image", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

最容易出错的点：

- `img[y, x]` 的顺序是先行后列，不是先 x 后 y。
- OpenCV 彩色图像是 `BGR`，不是 `RGB`。
- ROI 复制时，左右两边区域大小必须一致。
- 新版 NumPy 中不建议依赖 `itemset()`，直接使用 `img[row, col] = value` 更稳。
- 读取图片后最好先判断 `img is None`，避免路径错误导致后续属性访问失败。
